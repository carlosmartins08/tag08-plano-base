# Weekly Decision Guide (Conversion Learning Loop)

## Goal
Improve conversion with weekly changes based on behavior evidence, not opinion.

## Input Metrics (by lang + country + route)
- Sessions
- decision_lens_card_view
- hero_cta
- calculator_submit
- final_cta_click
- whatsapp_click
- Hero_to_Calc_pct
- Calc_to_Final_pct
- Final_to_WA_pct
- Lens_to_Hero_pct

## Weekly Ritual (30 min)
1. Read top 3 segments by sessions.
2. Find the main bottleneck (largest step drop).
3. Decide only 1 primary change for next week.
4. Define success threshold before publishing.

## Decision Rules
1. If Lens_to_Hero_pct < 25%:
- Adjust Decision Lens headline and first card title.
- Keep offer unchanged.

2. If Hero_to_Calc_pct < 35% and decision_lens_card_view is high:
- Hero promise is weaker than mid-page context.
- Test a clearer hero headline tied to diagnosis.

3. If Calc_to_Final_pct < 45%:
- Reduce friction in calculator output copy.
- Clarify next action with one sentence and one CTA.

4. If Final_to_WA_pct < 30%:
- CTA confidence block is weak.
- Add concrete expectation: response time, who answers, what user should send.

5. If WhatsApp is strong in pt/BR and weak in es/NON_BR:
- Route and message mismatch for intl segment.
- Localize CTA microcopy and opening WhatsApp message.

## Guardrails
- One major test at a time.
- No layout redesign and copy rewrite in same week.
- Keep event contract stable.
