# Content Entity Map (TAG08 Niche)

## Purpose

This document defines canonical entities, terms, and semantic relationships for all TAG08 landing pages.
Use it to keep SEO and AI retrieval consistent across copy updates and future pages.

## Core entity

- `TAG08 Studio`
- Type: strategic marketing consultancy
- Canonical role: partner for social-media content strategy, authority building, and conversion growth

## Service entities (canonical)

1. `Strategic social media content management`
- Synonyms allowed:
  - social media content strategy
  - strategic content operation
  - content growth management
- Avoid generic-only terms without strategic qualifier:
  - "social media management" (alone)

2. `Brand positioning through content`
- Synonyms allowed:
  - authority positioning
  - market positioning communication

3. `Qualified audience growth`
- Synonyms allowed:
  - qualified reach expansion
  - audience development with business intent

4. `Conversion-oriented communication`
- Synonyms allowed:
  - conversion-focused messaging
  - sales-oriented content strategy

## Problem entities (pain language)

Use these as recurring semantic anchors:

- inconsistent communication
- traffic without funnel logic
- low-quality leads
- lack of strategic method
- content volume without business impact

## Outcome entities (benefit language)

Use these as proof-oriented anchors:

- predictable growth cycles
- higher message clarity
- stronger market authority
- better lead quality
- decision-making supported by measurable signals

## Trust entities

- Google Business Profile reviews
- operational transparency
- clear process ownership
- no forced lock-in model

## Funnel entities

Canonical sequence:

- `hero_cta`
- `calculator_submit`
- `final_cta_click`
- `whatsapp_click`

Required shared dimensions:

- `lang`
- `section`
- `cta`
- `country`
- `route`

## Geographic and language entities

- Primary country: `BR`
- Core language: `pt`
- International handling: `es`, `en`, `fr`
- Contact route semantics:
  - `br` -> national path
  - `intl` -> international/spanish path

## Semantic consistency rules

1. Every page must connect:
- pain -> mechanism -> proof -> action

2. Avoid contradictory claims across pages:
- If one page frames TAG08 as strategic consultancy, no page should frame it as only tactical posting service.

3. Keep canonical service naming stable:
- Reuse the entities above before inventing new labels.

4. Use measurable language where possible:
- prefer "process", "cycle", "decision signal", "conversion step" over vague superlatives.

## AI search optimization rules

1. Keep entity names explicit in headings and section intros.
2. Repeat canonical terms naturally across hero, value proposition, FAQ, and CTA blocks.
3. Align metadata, structured data, and on-page language with the same entity set.
4. Treat `llms.txt`, `robots.txt`, `sitemap.xml`, and schema as synchronized contracts.
