# Copy QA Checklist

Checklist rapido para aprovar copy antes de publicar.

## 1) Clareza e prova
- Cada bloco traz pelo menos uma evidencia concreta de processo, criterio ou decisao.
- O texto explica o que acontece na pratica, nao apenas promessa.
- Existe frase de proximo passo claro para o visitante.

## 2) Linguagem humana
- Evitar repeticao de palavras de efeito no mesmo bloco.
- Evitar frases genericas que servem para qualquer empresa.
- Usar frases curtas, diretas, com sujeito claro.

## 3) Consistencia editorial
- Heading, subtitulo e apoio falam da mesma ideia central.
- O tom permanece premium sem exagero publicitario.
- Nao existe termo tecnico interno exposto ao visitante.

## 4) i18n e idioma
- Nao existe mistura de idiomas no mesmo locale.
- Nao existe texto quebrado com caracteres invalidos.
- PT/EN/ES/FR mantem a mesma intencao, com redacao natural em cada lingua.

## 5) Autenticidade
- Teste de realidade: um cliente real diria isso desse jeito?
- Teste de especificidade: se trocar o nome da marca, o texto ainda faz sentido para qualquer concorrente?
- Se a resposta for "sim", o bloco esta generico e precisa de revisao.

## 6) Validacao final
- Build sem erro de tipos i18n.
- Revisao visual desktop + mobile nos blocos alterados.
- Revisao de CTA: texto, contexto e destino coerentes.
